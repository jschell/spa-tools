F1 Tracker is a single-page dashboard for Formula 1 fans. It shows a live countdown to the next session (updated every second), a 7-day weather forecast for the race circuit, the current driver and constructor standings, the full season calendar with per-race session times, and the latest F1 news from six sources — all without any login, account, or configuration.

Race schedule and standings data come from the Jolpica API (a community-maintained successor to the Ergast F1 API). Weather forecasts use Open-Meteo, a free API that requires no key. News is fetched directly from six publishers’ RSS and Atom feeds by a scheduled GitHub Actions workflow. The tracker reads the resulting same-origin JSON cache, without a third-party conversion service. Refreshes are scheduled every 30 minutes; GitHub may delay scheduled runs. A warning appears when the cache is over six hours old or a selected source failed to refresh. If all sources fail, the workflow reports failure and preserves the previous cache.

Settings including preferred temperature unit, theme, refresh interval, and which news feeds to show are saved in the browser's local storage and persist across sessions.
